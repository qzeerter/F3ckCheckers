TraceScanner

Сверхбыстрый сканер и чистильщик системных следов
Ищет упоминания файлов и строк на дисках, в распакованном Prefetch и в реестре (включая зашифрованные и обфусцированные строки), после чего позволяет удалить найденные записи и подчищает следы собственного запуска.

Что умеет:
- Поиск в файлах и памяти реестра: обычный текст (ASCII, UTF-8, UTF-16LE/BE), Base64, ROT13, Reversed, Nibble-Swap, 8/16-bit XOR, динамический Rolling XOR, сдвиги и 32/64-битные хэши (`CRC32C`, `FNV-1a`).
- Нативная распаковка сжатых файлов Windows `Prefetch` (`MAM` / `XPRESS Huffman`) в оперативной памяти.
- Очистка пользовательских и системных кэшей (`BAM`, `MuiCache`, `UserAssist`, `RecentDocs`, `OpenSavePidlMRU`, `BagMRU`, `Compatibility Assistant\Store`, `$Recycle.Bin`).
- Автоматический выбор инструкций под любой процессор: `AVX-512BW` (Ryzen 7000/9000), `AVX2 + BMI2` (Ryzen 5000, Intel Core), `AVX2` (Ryzen 1000–3000) или `SSE2` (старые Intel Xeon / Core / AMD FX).
- Полная поддержка всех сборок Windows 10 (1507–22H2) и Windows 11 (21H2–25H2)
